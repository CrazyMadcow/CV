# 세종대학교 교수 지원용 포트폴리오 (검토용 초안)

`application/sejong.html`을 Chrome에서 열어 미리 볼 수 있습니다.
HTML과 CSS 및 `assets/img`가 같은 폴더 구조를 유지해야 이미지가 표시됩니다.
Windows의 PowerShell에서 `application/generate-pdf.ps1`을 실행하면 `dist/Kwangwoo_Jang_Sejong.pdf`가 생성됩니다.

주의: 본 PDF는 6쪽 포트폴리오 초안으로, 온라인 자기소개서(A4 2쪽 제한)와 별도입니다.
실제 지원 시 첨부 허용 여부와 기관별 자료 활용 권한을 확인해 주세요.
